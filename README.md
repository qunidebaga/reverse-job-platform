# 反转求职平台（Reverse Job）

> **求职者发作品，企业主动来挑 —— 把招聘翻过来。**

一款面向 3D 设计师、小程序开发、UI/UX 等创意与数字人才的作品优先求职平台。求职者用作品说话，企业按作品主动约人，告别简历海投、告别作品被埋没。

---

## 为什么是现在

- **传统招聘的失效**：简历在 HR 手里停留不到 30 秒，作品集藏在附件里，创意人才被"经验匹配"的机器过滤掉；
- **企业的真实痛点**：招设计 / 开发岗最怕"简历漂亮、作品一般"，看作品才靠谱——**作品即信用**；
- **供给过剩的市场**：求职者海投无回音，企业被无效简历淹没，中间层（作品展示 + 主动邀约）几乎空白。

## 我们怎么反转

```
求职者发布作品卡片（作品图 / 过程图 / 技能标签 / 期望方向）
        ↓
企业按标签 · 地区 · 类型浏览作品
        ↓
企业主动发起约谈（带留言）
        ↓
求职者接受 / 拒绝 —— 主动权回到求职者
```

没有海投、没有简历堆。平台只做一件事：**让好作品被对的企业看到**。

## 差异化

| 维度 | 反转求职平台 | 传统招聘平台 |
|---|---|---|
| 核心资产 | 作品与项目（过程图防伪，可验证） | 简历文本 |
| 投递方式 | 企业主动约谈，求职者反选 | 求职者海投 |
| 匹配逻辑 | 作品 + 标签 + 地区 | 关键词 + 经验年数 |
| 求职者体验 | 被"抢"，有掌控感 | 被"筛"，被动等待 |
